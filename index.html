Books you scan go to the queue in your own GitHub account. The Book Collection program on your PC does the rest (details, values, saving to your collection). Everything here is stored only in this browser.

How to make a token
  1. github.com → your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your queue repo (book-queue).
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy, paste above. It only reaches those repositories.
